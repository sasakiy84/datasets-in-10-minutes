# 基準の抽出元と編集例

版：1.0。抽出元は `docs/gemini-proofreading/` の12資料の採否と215件の実変更対。生の応答より、原資料と照合して採用・見送りを決めた記録を優先した。以下は一般化できる編集基準であり、個別データセットの事実を他資料へ転用しない。

| 抽出元 | 修正前／提案 | 採用後／判断 | 基準 |
|---|---|---|---|
| Global PIQA p10 | parallel集合は、…共通問題を各言語へ訳す。 | parallel集合では、…共通問題を各言語へ訳す。 | 作業主体と適用範囲を区別 |
| SciCode p5 | 338の生成対象の部分問題へ分けている。 | 生成対象となる338の部分問題に分けている。 | 数量と修飾先を対応させる |
| SciCode p26 | 80主課題は5分野にまたがる | 80の主課題は5分野にまたがる | 助詞を省きすぎない |
| Global PIQA p22 | …翻訳した。…確認する。 | …翻訳した。…確認した。 | 完了した作成工程の時制をそろえる |
| Global PIQA p22 | 最終103問とした。 | 数値と除外条件を保つ | 語の整理で事実を変えない |
| Global PIQA p23 | 言語の種類から「種類」を省く案 | 見送り | 言語・文字・地域の種類という数え方を保つ |
| CharXiv | 条件の「場合」を省く案 | 見送り | 条件付きの主張を一般化しない |
| MMMLU | データ引用の「メニクス」を修正する案 | 元データと一致するため保持 | 日本語の引用も校正で改変しない |
| SimpleQA Verified | Nguyen Karinaの語順を逆にする案 | 原著の著者欄と一致するため保持 | 人名を慣習だけで訂正しない |
| HLE | F/Gを一般的な記号解釈から関手とする案 | 原問題の定義を優先して保持 | 専門的事実は個別の定義で確かめる |
| MRCR v2 | 日本語の要約に全文の条件を期待させる | 要約を「要旨」と示し、英語全文を保持 | 原文・翻訳・要約の役割を明確にする |
| ScreenSpot-Pro | 表の欄名だけを実モデル名とする | Mythos（Fable 5欄）として根拠の注記を保持 | 表示名と評価対象を混同しない |
| 共通の組版判断 | 本文の数文字だけの折返しを解消する案 | 原則見送り | 意味のある校正と見た目の好みを分ける |

各例の詳細・ページ別来歴は該当する `docs/gemini-proofreading/{dataset}.md` と同名ディレクトリの記録にある。本スキルによる今後の校正は別方式として記録し、過去のGemini回答と混同しない。
