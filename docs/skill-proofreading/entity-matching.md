# Entity Matching：スキルによる日本語校正

Geminiは使用していない。Codexが日本語校正スキルをページごとに適用した。作成者とは別のサブエージェントもレビューした。

|ページ|修正前|修正後|理由|
|---|---|---|---|
|5|二つのデータは同じであるかを判定する|二つのレコードが同じ実体を指すかを判定する|判定対象・数量の単位・助詞を明確にする。|
|5|ラベルが同じなら文字列も同じとは限らない|同じ実体でも、名称や属性の表記が異なる|判定対象・数量の単位・助詞を明確にする。|
|18|データを各クラスで同じ数にする|学習ペアの正例と負例を同数にする|判定対象・数量の単位・助詞を明確にする。|
|27|全データから1000を評価する|validとtestを合わせて最大1,000ペアを評価する|判定対象・数量の単位・助詞を明確にする。|
|7|同じAmber Waves、度数は少し違う|Amber Wavesの度数差|訳ページでも通常タイトルを1行に保ち、意味を短く示す。|
|19|配布tableA.csvとtableB.csvの実行数|配布tableA.csvとtableB.csvの実測行数|処理の実行回数と表の行数を区別。|
|46|発売年が異なるBillyの正例|年の表記が異なるBillyの正例|BのReleasedはnan、2004日付はSong_Name内なので属性を断定しない。原文・訳・配布正解を維持。|
