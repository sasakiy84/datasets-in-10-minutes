# Primary sources and actual data

Read on 2026-10-28 JST. The following are Wikimedia's own documentation/distribution, with Creative Commons as the direct license publisher.

- [MediaWiki history dumps](https://wikitech.wikimedia.org/wiki/Data_Platform/Data_Lake/Edits/MediaWiki_history_dumps): complete content, schema details, monthly all-history snapshots, current/historical semantics, TSV conventions, partitioning and public initial release 2020-01 (snapshot2019-12). Saved oldid2433177. The overview's old76-column statement disagrees with its actual78-field schema table and the actual78-field rows. Slides use78; no invented schema migration.
- [MediaWiki history](https://wikitech.wikimedia.org/wiki/Data_Platform/Data_Lake/Edits/MediaWiki_history): complete definition and change history;2026-05 additions event_log_id/event_user_is_cross_wiki. Saved oldid2433178.
- [Page and user history reconstruction](https://wikitech.wikimedia.org/wiki/Data_Platform/Systems/Page_and_user_history_reconstruction): complete body, use cases, log formats, reverse reconstruction, conflicts; a separate intermediate state-table representation is not described as the public eventTSV.
- [FAQ](https://wikitech.wikimedia.org/wiki/Data_Platform/Data_Lake/Edits/MediaWiki_history_dumps/FAQ): complete body; edit-context cumulative fields.
- [Official HQL schema](https://gerrit.wikimedia.org/r/plugins/gitiles/analytics/refinery/+/refs/heads/master/hql/mediawiki/history/create_mediawiki_history_table.hql): downloaded and decoded official create-table source, compared field order against documentation; the internal table includes page_artificial_id and the snapshot partition; excluding those gives exactly the public78-field order. The official MediawikiEvent.toTSVLine explicitly omits pageArtificialId.
- [Public distribution](https://dumps.wikimedia.org/other/mediawiki_history/):2026-08/2026-09 directories observed. Snapshot2026-09 directories date2026-10-05. Small wiki directory selection and complete nawiki file obtained, not a prefix sample. Larger global/enwiki dump not acquired.
- [Actual nawiki file](https://dumps.wikimedia.org/other/mediawiki_history/2026-09/nawiki/2026-09.nawiki.all-time.tsv.bz2):6,194,151compressed bytes;116,372 rows, all78 columns. Entire file parsed; all displayed fields and aggregates compared to these records. This small languagewiki is an example for local use, not representative of all Wikimedia editing.
- [MediaWiki History Data](https://dumps.wikimedia.org/other/mediawiki_history/readme.html): official distribution notice explicitly applies CC0. Its older array(...) notation is not substituted for current dump documentation and actual file conventions.
- [MediaWiki Content File Exports](https://wikitech.wikimedia.org/wiki/MediaWiki_Content_File_Exports): definition/content/current/history sections read for the distinction from article-body corpora; migration/sunset details are outside this deck.
- [CC0 1.0 legal code](https://creativecommons.org/publicdomain/zero/1.0/legalcode.en): exact notice retained. Wikitech's footer separately links CC BY-SA4.0 for documentation text.

No Gemini or external generation API or benchmark/model evaluation was used. Local Python parsing, aggregate calculations, editable native charts and LibreOffice PDF export were used.
