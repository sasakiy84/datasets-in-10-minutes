# BrowseComp：スキルによる日本語校正とレビュー

Geminiは使用していない。ローカルの制作・日本語校正スキルで作成し、作成担当とは別の担当が内容・原票・描画を確認した。以下は実際に行った修正の対である。最終版の確認範囲とファイルの対応は検証票に記録した。

|ページ・対象|修正前|修正後|理由|
|---|---|---|---|
|11|建物の規模だけでなく、近隣のモスクと病院の歴史も照合する。面積と収容人数は別々の条件である。|建物の規模だけでなく、近隣のモスクと病院の歴史も照合する。|質問の条件から自明な注意書きを除き、探索の説明を保つ。|
|41|物語の特徴で候補を探した後、雑誌のページ数と出版社名を照合する。筋の要約だけで掲載先を決めない。|物語の特徴で候補を探した後、雑誌のページ数と出版社名を照合する。|探索手順の説明を保ち、一般的な禁止の補足を除く。|
|16|人が探しても、多くは2時間以上かかる|人の調査でも、7割が探索を断念した|完了所要時間と未解決の断念を混同しない。|
|18|正解率は、正しいと判定された問題の割合。検索の回数や回答の長さは、そのまま得点にはならない。|正解率は、正しいと判定された問題の割合。|定義から分かる注意の繰返しを削る。|
|23|派生版では、集めた文書を文脈として渡す。|派生版では、公開URLからページの文書を取得し、文脈としてモデルに渡す。|配布されるURLと実際の文書入力の関係を明示する。|
