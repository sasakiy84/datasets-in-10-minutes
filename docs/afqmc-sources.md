# AFQMC source and validation notes

AFQMC = Ant Financial Question Matching Corpus (official CLUE README and formal paper). The deck presents the corpus independently, followed by CLEVA adoption. 2020 in metadata is the CLUE publication year, not an asserted original competition launch year. Native Japanese PPTX/PDF, author sasakiy84, no notes. No Gemini or external generation/scoring API.
