## 掲載した実例と取得範囲

今回は本編3課題とAppendix1課題、合計4課題を掲載した。配布全件のParquetとプレビューAPIの接続先が環境の許可リストに入っておらず、取得できた一次資料の範囲で制作した。通常の追加10件程度には達していない。架空の課題、同じ課題の言い換え、省略表示から推測した続きを追加していない。

Hugging Face公式配布ページのHTMLに含まれるデータプレビューは10行だが、問題文・正解条件・操作履歴を全文確認できるのは先頭3行。行3以降は100文字前後に切られているため使っていない。ページ番号の指定も取得したHTMLでは先頭表示に留まり、他の行を確認済みとはしていない。全500課題を取得・独自集計したとは主張しない。

本編の原文はプレビューの `PROMPT` と一致する。日本語の説明は翻訳・要約、正解条件の表は `GTFA_CLAIMS` の日本語要約。医学論文の全文要旨やスペイン語訳そのものを再掲したとはしていない。論文中の追加例も日本語で要約した。各ページにデータの出所とIDを置いた。

3課題について `GTFA_CLAIMS` をリストとして読み、`TRAJECTORY` は末尾までJSONとして解析できることを確認した。操作履歴の主要ツールは次のとおり。

- AssaultCube：GitHub検索 → リポジトリ確認 → Web取得 → WHOIS → コードによる年差計算。
- 製品売上：Exa検索 → Airtableのbaseとtableを探す → レコード照会 → Exa検索。
- 医学論文：arXiv検索 → Lara翻訳 → DuckDuckGo検索 → Web本文取得。

## 収集・集計・採点の根拠

作成・検証・文書化の平均4.6時間、5段階の品質確認、正解条件平均4.7項目（1〜23）、提示ツール平均15.2（6〜37）、必要ツール平均4.1（2〜8）、参照履歴平均9.8呼び出しは論文v3に基づく。

分野別の32%・22%・22%・12%・12%、必要サーバー数別の1.4%・51.7%・38.2%・8.7%、上位サーバーの課題数155・133・108・99・98・96も論文v3の集計。サーバーを複数使う課題は98.6%、平均2.55サーバー。公開プレビューの3行から全体を推定していない。

失敗診断は論文の約6,900件についての63.3%（認知側）・36.7%（ツール呼び出し側）。4種類と7種類の分類をAppendixに掲載。全課題や全出力の割合へ分母を置き換えていない。

公式 `CoverageEvaluator.evaluate` のASTから得た集計処理を、判定済みの値を返すローカルの代役とともに実行した。fulfilled / fulfilled / not_fulfilled が0.667、fulfilled / partially_fulfilled が0.75となることを確認した。公式 `_compute_split_stats` で0.667・0.75・1.0の3課題を集計し、0.75以上の合格率66.67%も確認。これは掲載した算術と境界値の確認であり、モデルによる判定性能の実験は行っていない。モデルAPI呼び出し、Docker上の36サーバー実行、ベンチマーク全件の再実行も行っていない。

配布履歴には2025-12-12の `MCPAtlas-v1.parquet` アップロードと `MCP-Atlas.parquet` への改名があり、以後の履歴はREADMEの更新だった。ギャラリーでは配布データの初回アップロード年2025を採用し、論文の2026とは分けた。データの最終改訂ID、論文v3、エージェント実行プログラムのバージョン2.0.0を資料内で別々に説明する。

現行READMEの307というツールカタログ数と、論文・データカードの220という課題内のツール数は異なる対象の記載である。資料のベンチマークの説明は論文v3の220を使い、307と合算・置換していない。データカードの提示ツール10–25、操作3–6という記載も論文v3の定義とは異なるため、全体の構成・規模は論文v3に合わせた。

## 画像・表示・構造の確認

冒頭はHugging Faceの公式配布ページ。ブラウザーで4件のCSSとSource Sans Proの適用、実際のデータ表と見出しを確認して撮影した。Scaleのリーダーボードは接続制限で取得できず、HF画面を公式トップページとは呼んでいない。外部アバター・ライセンスバッジ・決済/WAF関連の一部は読み込めなかった。画面上で主要なデータ表が表示されることは目視した。

共通マスターとNoto Sans / Noto Sans CJK JPを使用。コードはLiberation Mono。表紙52pt太字、左上帯14pt太字。16個の編集可能な表、3個の編集可能なグラフを含む。表は上下1.2pt、見出し境界0.6pt、縦罫なし。発表者ノートなし。

全50枚を一覧で確認し、表・引用・コード・グラフ・参考文献の26枚を1440×810で1ページずつ拡大確認した。医学課題の長い原文と日本語説明の重なりを修正し、表セルの末尾だけの改行も解消した。タイトル・表セルの1〜2文字だけの折り返しは調整し、本文などの短い最終行は許容する、新しい共通SKILLの方針を適用した。

全段落のPPTX・PDF照合、文字欠落・ページ外文字・タイトルの想定外の改行がないことを確認。全表のセル・罫線・表注の位置を検査した。本文と出典の最小間隔は約9.1pt、コード背景の上下余白は各約11pt、2件の参考文献の最小間隔は約36.7pt。URLだけに付いた42件のリンクも確認した。

PPTXのZIP・内部参照、68 XMLパーツを検査し、既知の箇条書きパーセント表記以外のスキーマエラーなし。確認した最終PPTX・PDFを、再生成せずそのまま納品ファイルへコピーした。
