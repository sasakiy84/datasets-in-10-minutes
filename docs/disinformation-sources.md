## Metrics and unresolved primary-source differences

Self-BLEU strips/drops blank completions, compares each against the others using sacrebleu BLEU(effective_order=True), averages, and returns0 for≤1 nonblank result. It is in0–100; higher means greater wording overlap. It is not reference headline accuracy. Monte Carlo entropy averages each completion's negative SUM of token logprob, in nats; it is not per-token normalized and is biased at non-unit temperature when logprobs use a different distribution. It is not full-vocabulary exact entropy. recheck_metrics.py uses local sacrebleu2.3.1 and recomputes all215 requests/1075 outputs:12 topic/sub_split aggregate checks match saved public stats within1e-9. The per-request recomputed values are saved; the public comparison is at aggregate level. Example1 sums14.659738/7.787492/9.193671/17.169002/8.881212, mean11.538223nats.

Human metric implementation looks up stored annotations by model+thesis or model+first prompt line; it does not compare the current candidate's output string. The2 CodaLab annotation URLs returned503 and their original annotation rows could not be independently reaggregated. Presentation human tables use saved public stats, not newly assigned judgments to the13 displayed outputs. Three selected models' reiteration aggregates are weighted31COVID+37climate; wedging sub_split statistics weighted5/3/1/2 so each of11 inputs has the same weight. This is the documented own aggregation, not an assertion about the web UI's group macro average. Reiteration support/style use1–5; wedging audience/goal/division/style use−1–1, hostility0–2. Hostility is a human rating, distinct from automatic toxicity scores. Table8's selected model values agree at displayed precision.

HELM §8.5.1 says3 annotators per generation, Appendix E.5 says5. Both statements are retained; the difference is unresolved. The published work estimates11min×2=22min per task and pays$5.50, equivalent to$15/hr; it includes instruction secret-word checks and warns workers about potentially false/offensive generated text.

Appendix E.5 reports114COVID+147climate headlines=261; downloaded JSONL has89+132 headline slots=221 including repeated strings, with74/104 unique strings. Both counts are recorded.
