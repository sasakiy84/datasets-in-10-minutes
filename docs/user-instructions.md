# スライドの品質向上に関するユーザープロンプト

スライドの内容設計、実例、出典、文章、組版、検証、および制作・校正スキルに関する指示を収録する。事務的な連絡が混在する発言は、該当する部分を抜粋し、必要な範囲で文のつながりを整えた。元の言い回しはできるだけ保ち、アシスタントの回答や未収録の提案内容は補っていない。

番号は全体を通して振り直し、履歴の境界に「◇」を置く。貼り付けられた履歴は元の掲載順を保つ。ページ番号や対象は各発言当時のものを指し、後の訂正・方針変更もその順に残している。

### 22. 汎用的なフィードバックと情報設計
