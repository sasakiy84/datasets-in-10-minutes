# Wikidata の利用条件と帰属

構造化データの出所はWikidata contributors、各項目のSpecial:EntityData（スライドの出典URL）である。個別の版IDと取得記録はデータ記録に保持している。

- Main、Property、Lexeme、EntitySchema名前空間の構造化データはCC0。項目のラベル・説明・別名・文も含む。 https://www.wikidata.org/wiki/Wikidata:Licensing
- CC0 1.0 Universalの案内： https://creativecommons.org/publicdomain/zero/1.0/
- 他の名前空間の文章はCC BY-SA 4.0。公式ヘルプの内容を要約・日本語で説明した。 https://creativecommons.org/licenses/by-sa/4.0/
- 公式トップ画面の出所はWikidata contributors、Wikidata:Main Page。参照2026-10-28。元URLは https://www.wikidata.org/wiki/Wikidata:Main_Page 。ページ本文はCC BY-SA 4.0（ https://creativecommons.org/licenses/by-sa/4.0/ ）。画面内容は変更せず、取得したスクリーンショットを縮小して配置した。画面中のロゴや画像は構造化データのCC0とは別の条件に従う。各ファイルの帰属・条件は元画面のリンク先で確認できる。

本資料の図表は取得した実データを選択・換算・整形したもので、Wikidataが本資料を承認・推薦していることを示さない。
