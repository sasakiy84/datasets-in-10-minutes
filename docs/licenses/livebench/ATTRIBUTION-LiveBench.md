# LiveBench data attribution and display scope

LiveBench was introduced by Colin White and coauthors, sponsored by Abacus.AI. The official Datasheet for LiveBench declares distribution under Apache License 2.0. The repository's literal LICENSE retains FastChat Apache and LiveCodeBench MIT components; it is included separately and is not used to claim that source contest questions are MIT.

This Japanese educational introduction selects 13 public questions from official livebench Hugging Face families at the revisions listed in examples.json. Original questions and supplied gold values remain attributable to LiveBench and their credited sources. Japanese translations and explanatory text were added for this deck. Formatting changes include semantic wrapping, native math equivalents for math questions, and explicit whitespace expansion for the TSV display; the typo task preserves literal $n$.

Underlying-source attributions retained in selected records: the Guardian for the short news-based instruction-following prompt; the New York Times Connections (via the credited puzzle site) for two eight-word puzzles; the coding task's AtCoder origin via LiveCodeBench. No source credit is removed. The movie-plot candidate whose original source could not be fixed was excluded before drafting.

Main and Appendix examples are 2024-06-24/2024-07-26 releases of the original LiveBench series; some later have removal dates. These are historical public examples, not claimed to be the current 2.0 task set. Public version 2.0 score and methodology files are used to describe the October 2026 transition; no unpublished tasks are reconstructed.
